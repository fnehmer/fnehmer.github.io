The shell is called `/usr/bin/showtext`. We have a look at it

```bash
$ vim /usr/bin/showtext
```

```bash
#!/bin/sh

export TERM=linux

more ~/text.txt
exit 0
```
At first the script sets a environment variable called `TERM`, then ist displays a text with `more` then it exits with `exit 0` The exit is where we get kicked out, so we need to not reach this statement or retrieve the flag before this statement is reached

We investigate `more`:

```bash
$ man more

[...]

more is a filter for paging through text one screenful at a time. 

[...]
```

One screenful at a time means that we have to use paging when the content is bigger than our window, so we somehow need to force the content in `text.txt` to be paged. The key is to shrink the window so that less lines are displayed, than the text.txt has, so we do not get disconnected.

```bash
$ ssh -i key.priv -p 2220 bandit26@bandit.labs.overthewire.org
```
