# Krypton Level 1 → 2

Log in with `krypton1` user via ssh and the password `KRYPTONISGREAT`
```bash
$ ssh -p 2222 krypton1@krypton.labs.overthewire.org
```

We change the directory to the challenge directory and check it out

```bash
$ cd /krypton/krypton1

$ ls -la

total 16
drwxr-xr-x 2 root     root     4096 Sep 23 04:24 .
drwxr-xr-x 8 root     root     4096 Sep 23 04:24 ..
-rw-r----- 1 krypton1 krypton1  882 Sep 23 04:24 README
-rw-r----- 1 krypton1 krypton1   26 Sep 23 04:24 krypton2
```

Reading the `README` we find out that we need to use ROT13 on krypton2 in order to get the password. We do this by using the tool `tr` (translate). We only need to capital ASCII letters.

```bash
$ cat krypton2 | tr A-MN-Z N-ZA-M

LEVEL TWO PASSWORD ROTTEN
```# Krypton Level 0 → 1
