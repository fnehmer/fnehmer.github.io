We analyse the messages by dividing each message into chunks of 6 letters. Then we do a frequency analysis on every first, second, ..., sixth letter of every chunk. (For simplification we throw away the last letters of every message, which do not add up to a full chunk anymore). For every position in a chunk we assume, that the letter `E` is the most probable one,so we assume, that the letter with the most occurences on a position will decrypt to `E`. 

`vig_freq_analysier.py`

```python
import sys
from collections import Counter, OrderedDict

data = sys.stdin.read().replace(" ", "")

chunks = []
cur_chunk = ""

for i in range(len(data)):
        cur_chunk += data[i]
        if len(cur_chunk) == 6: # Get rid of incomplete chunk at the end
                chunks.append(cur_chunk)
                cur_chunk = ""

character_list = []

for i in range(len(chunks)):
        if i%6 == 0 and len(chunks[i]) == 6:
                character_list.append(chunks[i][0]) # Here you can change the character position which gets analysed

print(str(Counter(character_list).most_common(10)) + "\n")
```


Doing so gives us they key `FREGTY`. We test it out with the messages. In order to do this we implement a vigenere decrypter for our alphabet.

`vig_decrypt.py`

```python
def decrypt(msg, key):
  result=""
  msg = msg.replace(" ", "") # strip spaces

  for i in range(len(msg)):
    pos = i%6 # cycle through key

    # current character which gets decrypted
    enc_letter = ord(msg[i]) 

    # get the shift distance
    key_shift = (ord(key[pos]) - 65) 

    # decode with shift distance
    dec_letter = enc_letter - key_shift
    if dec_letter < 65: # handle 'underflowing' ASCII decimal representation
      dec_letter = 90 - (65-dec_letter- 1)
    
    # build result
    result += chr(dec_letter)
  print(result)

if __name__ == "__main__":
  decrypt("YYICS JIZIB", "FREGTY...")
```

Both messages start with `THE`. Also at the first three characters of every chunk we could make out a most frequent character. So we assume for now, that the first three characters of our key are correct. The 4th character was quite uncertain since there were two evenly frequent characters `K` and `D`.

We now 'brute-force' the rest of the keys, with the information we have about frequently used letters in english language.
* 4th character
  * `E` encrypts to `K` → `G` 
  * `T` encrypts to `K` → `R` 
  * `E` encrypts to `D` → `Z` 
  * `T` encrypts to `D` → `K` 
* 5th character
  * `E` encrypts to `X` → `T` 
  * `T` encrypts to `X` → `E` 
* 6th character
  * `E` encrypts to `C` → `Y` 
  * `T` encrypts to `C` → `J` 

This leaves us with the following 16 combinations:

`FREGTY`, `FRERTY`, `FREZTY`, `FREKTY`, `FREGTJ`, `FRERTJ`, `FREZTJ`, `FREKTJ`,
`FREGEY`, `FREREY`, `FREZEY`, `FREKEY`, `FREGEJ`, `FREREJ`, `FREZEJ`, `FREKEJ`

By trying those out we find out, that the key is `FREKEY`
