# Krypton Level 2 → 3

Log in with `krypton2` user via ssh and the password `ROTTEN`
```bash
$ ssh -p 2222 krypton2@krypton.labs.overthewire.org
```

We change the directory to the challenge directory and check it out

```bash
$ cd /krypton/krypton2  

$ ls -la

total 32
drwxr-xr-x 2 root     root     4096 Sep 23 04:24 .
drwxr-xr-x 8 root     root     4096 Sep 23 04:24 ..
-rw-r----- 1 krypton2 krypton2 1815 Sep 23 04:24 README
-rwsr-x--- 1 krypton3 krypton2 8970 Sep 23 04:24 encrypt
-rw-r----- 1 krypton3 krypton3   27 Sep 23 04:24 keyfile.dat
-rw-r----- 1 krypton2 krypton2   13 Sep 23 04:24 krypton3
```

The `README` tells us that we deal wit caesar cipher and that we should set up a working environment in `/tmp`

We set up our working environment in `/tmp`

```bash
$ mktemp -d

/tmp/tmp.PRift0sljy

$ cd /tmp/tmp.PRift0sljy

$ ln -s /krypton/krypton2/keyfile.dat

$ chmod 777 .

$ cp /krypton/krypton2/krypton3 ./krypton3

$ cp /krypton/krypton2/README ./README
```

We look at the cipher text

```bash
$ cat ./krypton3

OMQEMDUEQMEK
```

To see how much it is shifted we encrypt the Alphabet. We could just use one letter to check the shift distance, but for visualization we use the full alphabet

```bash
$ echo ABCDEFGHIJKLMNOPQRSTUVWXYZ > test.txt

$ /krypton/krypton2/encrypt ./krypton3

$ cat ciphertext

MNOPQRSTUVWXYZABCDEFGHIJKL
```

With this information we build our translate `tr`

```bash
$ cat krypton3 | tr M-ZA-L A-Z

CAESARISEASY
```
